## 0. 文档说明与范围边界

本文件是栖木家具官网（**前台展示官网 + 后台内容管理系统**）的 **UI/UX 单一可信来源（Single Source of Truth）**，供前端（React + Tailwind CSS）、后台（React + Ant Design）、设计走查、验收与迭代共同遵循。

**本期明确包含：**
- 前台：5 个顶部主导航 + 全部二级栏目、首页六区、产品中心、新闻、案例/招聘静态页、关于我们、留言/询价表单、响应式与动效。
- 后台：登录与鉴权、仪表盘、内容管理（产品/新闻/Banner/企业资料）、互动管理（留言/询价）、系统管理（用户/角色 RBAC）；双端设计系统与令牌。
- 专项：无障碍与合规（PIPL）、性能与响应式基线、组件/状态清单、设计走查清单。

**本期明确不包含（仅文档化、不设计维护界面）：**
- 「新案例展示」「招聘入口」：静态呈现，后台无维护能力，文档仅描述呈现规则。
- 产品详情"相关产品推荐"、价格展示、C 端账户体系：本期不做，标注为后续迭代。
- 图表的**可视化图片**：后台仪表盘图表的类型选择与使用规范以文字描述为主，开发阶段由前端按规范实现（不在此文档产出图片）。

**交付格式：** 单个 Markdown 文件（与 PRD 约定一致），内嵌全部表格，不依赖外部图片。

## 1. 设计原则与方法论

### 1.1 设计价值观

| 原则 | 前台（品牌官网） | 后台（管理系统） |
|---|---|---|
| 核心目标 | 传递"东方木作、温润高级"的品牌信任感 | 高效、规范、安全地运营官网内容 |
| 视觉语言 | 暖色木调 + 衬线标题，克制留白 | Ant Design 中性冷调，信息密度优先 |
| 体验基调 | 沉浸、从容、有呼吸感 | 清晰、可控、反馈即时 |
| 决策依据 | 品牌调性 > 转化效率 | 操作效率与权限安全 > 装饰性 |

### 1.2 目标用户（对齐 PRD 1.3）

- **前台访客**：潜在经销商、采购方、求职者、普通消费者、媒体——以"浏览—信任—留言/询价"为主线。
- **后台用户（员工）**：超级管理员、内容编辑、客服/运营——以 RBAC 约束操作边界。

### 1.3 方法论框架（采用 ui-ux-pro-max 技能 8 大优先级）

文档全程以以下 **8 大优先级** 作为设计判据与走查基线（括号内为优先级等级）：

1. **无障碍 Accessible（CRITICAL）**：对比度、键盘可达、focus 环、aria 标签、表单 label。
2. **触摸与交互 Touch & Interaction（CRITICAL）**：点击热区 ≥ 44×44px、悬停/激活态、防误触、加载与空/错态。
3. **性能 Performance（HIGH）**：首屏 < 2s、图片优化、懒加载、接口响应。
4. **布局与响应式 Layout / Responsive（HIGH）**：栅格、断点（1024 / 768）、固定栏不遮挡内容。
5. **字体与颜色 Typography / Color（MEDIUM）**：字号阶梯、行高、语义色、品牌色一致。
6. **动画 Animation（MEDIUM）**：克制、一致、可降级（`prefers-reduced-motion`）。
7. **风格选择 Style Choice（MEDIUM）**：双端风格各守其位，不混用。
8. **图表与数据 Charts / Data（LOW）**：类型恰当、读数清晰、不冗余。

### 1.4 反模式（开发须规避）

- **禁用 emoji 图标**：一律使用统一 24×24 线性 SVG（前台 `stroke-width:2`，后台 `stroke-width:2`）。
- **统一图标尺寸**：图标统一 `24×24`（紧凑控件可 16–20）；前台 SVG 默认 `width/height` 与 `currentColor` 着色。
- **亮/暗对比底线**：正文文本与背景对比度 ≥ 4.5:1（WCAG AA）；后台暗色侧栏文字 `rgba(255,255,255,.78)` 配 `#0F1B2D`。
- **浮动导航间距**：前台 `header.nav` 固定 `top:0`，`height:68px`，内容区须预留 `margin-top:68px`（Hero 已处理；各页 `padding-top:96px`），避免被固定栏遮挡。
- **内容不被固定栏遮挡**：后台固定 `header:56px` + `sider:232px`，`content` 区域内滚动，不溢出壳层。
- **不可用纯颜色传达状态**：状态须配文字/图标（如"上线/下线"标签 + 颜色）。
- **不混用设计语言**：前台衬线标题与后台无衬线控件不可跨端混用令牌。

### 2.2 字体排版

| 维度 | 前台（品牌） | 后台（AntD） |
|---|---|---|
| 标题字体 | `--serif`: "Songti SC","STSong","SimSun",Georgia,"Noto Serif SC",serif | 系统无衬线（同 body） |
| 正文字体 | `--sans`: "PingFang SC","Microsoft YaHei","Hiragino Sans GB",Arial,sans-serif | `--sans`: "PingFang SC","Microsoft YaHei","Helvetica Neue",Arial,sans-serif |
| 基础字号 / 行高 | `16px` / `1.7` | `14px` / `1.6` |
| 标题字重 / 行高 | `600` / `1.3` | `600` / 默认 |
| 标题字号阶梯 | H1 `46px`（Hero）、H2 `32px`（区块）、H3 `22px`、H4 `18px` | 页标题 `20px`、卡片标题 `15px`、统计数字 `26px` |
| 正文阶梯 | 正文 `16px`、摘要 `13–14px`、弱化 `12–13px` | 表格 `14px`、标签 `12px`、说明 `13px` |

**规则：**
- 前台标题一律衬线；后台标题与正文均用无衬线。
- 字号下限：正文 ≥ `14px`，辅助文字 ≥ `12px`；移动端不缩小基础正文。
- 中文优先回退到 `PingFang SC` / `Microsoft YaHei`，保证一致渲染。

| 维度 | 前台 | 后台 |
|---|---|---|
| 容器 `max-width` | `1200px`（`.wrap`，`padding:0 24px`） | 自适应（sider 固定，content 流式） |
| 区块间距 | `.section` `padding:72px 0`（移动端 `48px 0`） | `.card` `padding:20px`；页头 `margin-bottom:18px` |
| 栅格间距 | `gap:20–24px`（卡片）、`48px`（双栏） | `gap:16px`（统计卡）、`10–12px`（筛选） |
| 圆角 | 卡片 `12px`、控件/小卡 `8px` | 卡片/输入 `8px`、统计卡 `10px`、头像 `50%` |
| 阴影 | `--shadow:0 6px 24px rgba(92,65,40,.08)`；`--shadow-lg:0 16px 48px rgba(92,65,40,.14)` | `--shadow:0 1px 2px rgba(0,0,0,.06),0 2px 8px rgba(0,0,0,.04)` |
| z-index | nav `50` / dropdown `60` / modal `80` | drawer `80` / modal `90` / toast `99` |

### 2.4 图标规范

- **来源**：统一内联 24×24 线性 SVG，`viewBox="0 0 24 24"`、`fill="none"`、`stroke="currentColor"`、`stroke-width="2"`。
- **着色**：`currentColor` 继承父级 `color`；前台图标色多为 `--primary` / `--accent` / `#fff`；后台图标色随令牌。
- **禁用**：emoji、彩色 PNG 图标、不一致尺寸（紧凑控件允许 16–20px，但须成比例）。
- **装饰性图标**：加 `aria-hidden="true"`；功能性图标（如菜单、关闭）须有 `aria-label`。

### 2.5 栅格与断点

| 断点 | 前台适配 | 后台适配 |
|---|---|---|
| `>1024px` | 桌面：4 列系列 / 3 列产品·新闻·案例 | 桌面：4 列统计卡、sider 展开 |
| `≤1024px` | 2 列网格、双栏转单栏 | 2 列统计卡 |
| `≤768px` | 单栏；导航转汉堡菜单；Hero `440px` | sider 抽屉化；表单单栏 |

**全局尊重**：`@media (prefers-reduced-motion:reduce)` 关闭所有动画与过渡。

## 3. 前台 UI/UX 规范

### 3.1 信息架构与全局框架（对齐 PRD 3.1）

```
顶部固定导航（68px，毛玻璃）
├─ 首页
├─ 产品 ─ 产品中心 / 新案例展示（静态）
├─ 新闻 ─ 企业新闻 / 行业资讯
├─ 招聘入口 ─ 社会招聘（静态）/ 校园招聘（静态）
└─ 关于我们 ─ 关于栖木家具 / 发展历程 / 品牌介绍 / 联系我们
Hero 轮播 → 品牌实力 → 产品系列入口 → 新闻动态 → 招商·招聘入口
页脚（深胡桃底）
```

**导航交互：**
- 浮动固定 `position:fixed; top:0`；`background:rgba(250,247,242,.88)` + `backdrop-filter: blur(12px)`；`border-bottom:1px solid var(--border)`。
- 一级项 hover 显示下拉二级（`.dropdown`，`top:54px`，hover 渐显）；当前项 `.active` 高亮（主色浅底 + 深胡桃文字）。
- 二级 `aria-haspopup` / `aria-expanded` 正确绑定；移动端 `aria-expanded` 切换内联展开。
- 右侧 CTA「留言 / 询价」`btn-quote`：`≤768px` 隐藏，由汉堡菜单承接。

### 3.2 首页六区规范

| 区块 | 关键组件 | 交互/状态 |
|---|---|---|
| Hero 轮播 | 3 张 Slide（渐变底 + 文案 + CTA）；左右箭头；底部圆点；自动播放 5s | hover 暂停；`aria-label` 上/下一张；`prefers-reduced-motion` 不自动播放 |
| 品牌实力 | 左文案 + 右 2×2 统计卡（成立年份/厂区/产线/客户） | 数字衬线大字 `--primary` |
| 产品系列入口 | 4 列系列卡片（封面渐变 + 名称 + 描述） | hover 上浮 `translateY(-6px)`；点击进产品中心并按系列预筛选 |
| 新闻动态 | 3 列新闻卡（取最近 3 条） | 点击开详情模态 |
| 招商·招聘入口 | 2 列 recruit-card（城市招商 / 人才招聘） | CTA 跳转联系/招聘页 |
| 页脚 | 4 列（品牌/产品/资讯/联系）+ 备案行 | 深胡桃底 `#5C4128`，链接 hover 变金 |

### 3.3 产品模块规范

- **产品中心**（`/products`）：筛选区（关键词输入 + **系列 chips** + 适用空间 chips + 搜索按钮）；列表 3 列卡片；分页每页 6 条；空态「未找到匹配产品」。系列与空间为并列单选高亮筛选，二者可叠加。
- **筛选状态**：`{kw, space, series, page, pageSize:6}`；空间与系列 chips 均单选高亮（`--primary` 实心）；首页入口可预选 `series`，页面内仍可改选。
- **产品卡片**：封面渐变 + 家具 SVG、名称、系列/空间 meta 标签、`查看详情` 链接（accent 色）。
- **产品详情（模态）**：图片画廊（封面 + 多图，≥1 张）、规格 2×2（系列/空间/材质/尺寸/风格/**价格=暂不展示**）、图文详情、底部「对此产品留言/询价」CTA 带入产品信息。
- **无价格**：详情规格中"价格"项固定显示「暂不展示」（灰），不预留价格字段 UI。
- **本期不做**：相关产品推荐（后续迭代）。

### 3.4 新闻与静态页规范

- **新闻列表**：Tabs（企业新闻 / 行业资讯）；3 列卡（封面渐变 + 日期 + 标题 + 2 行摘要）；按发布时间倒序。
- **新闻详情（模态）**：封面 + 来源/发布时间 + 正文。
- **新案例展示（静态）**：3 列 case-card（封面 + 标题 + 简介），数据来自后端静态配置/前端内置（PRD 6.6）。后台无维护入口。
- **招聘入口（静态）**：社会/校园 2 列 recruit-card（岗位方向 + 我们提供）；纯文案展示，提示"以后期官网正式发布为准"。后台不维护。

### 3.5 关于我们规范

- **关于栖木家具**：长文排版（`max-width:820px`，`line-height:1.9`），真实企业介绍；后台 `about:manage` 可维护富文本。
- **发展历程**：竖向时间轴（`.timeline` + 圆点节点），年份衬线大字。
- **品牌介绍**：3 列 brand-card（图标 + 标题 + 描述：东方美学/匠心工艺/绿色责任）。
- **联系我们**：左信息卡（地址/电话/邮箱/社交 + 地图嵌入位）+ 右留言表单。
  - **留言/询价表单字段**：姓名（必填）、电话（必填，pattern 校验）、邮箱（选填）、类型（留言/询价）、关联产品（选填下拉）、内容（必填）、隐私同意勾选（必填）。
  - **提交**：前端校验 → POST `/api/v1/messages` → Toast「提交成功」→ 重置表单。隐私提示明示收集目的与最小必要（对齐 PIPL，见第 5 章）。

### 3.6 表单与反馈

- **输入态**：`border:1px solid var(--border)`，focus `border-color:var(--primary)`（无 outline 边框高亮）。
- **必填标记**：`*` 用 `--danger` 色。
- **Toast**：底部居中 `toast`，深底白字，显示 ~2.6s 自动消失，`z-index:90`。
- **模态**：`modal-mask` 半透明 + `blur(2px)`，居中 `max-width:760px`，`pop` 入场动画；关闭：遮罩点击 / `Esc` / 关闭按钮 / `data-close`。

### 3.7 动效规范

- **时长**：过渡 `.2s`、入场 `.25s`；Hero 淡入 `.8s`。
- **位移幅度**：卡片 hover 上浮 `5–6px`。
- **可降级**：`prefers-reduced-motion:reduce` 全量关闭动画/过渡/平滑滚动。
- **风格**：克制、与品牌从容基调一致，不出现弹跳/闪烁。

## 4. 后台 UI/UX 规范（Ant Design 风）

### 4.1 整体布局

```
登录页（满屏渐变）→ 后台壳：
├─ Sider（暗色 #0F1B2D，232px，可收起 64px）
│   ├─ 品牌行（logo + 名称）
│   └─ 菜单（仪表盘 / 内容管理 / 互动管理 / 系统管理，含子菜单）
└─ Main（Header 56px + Content 流式滚动）
    ├─ Header：折叠按钮 + 面包屑 + 角色徽章 + 用户 + 退出
    └─ Content：页面头 + 卡片/表格/筛选/分页/弹窗
```

### 4.2 登录与鉴权 UX（对齐 PRD 5.1）

- **登录页**：卡片式（400px），用户名 + 密码 + 登录按钮；角色快捷填充（超级管理员/内容编辑/客服·运营）用于演示。
- **失败反馈**：`login-err` 红底提示条；连续失败 **5 次 / 10 分钟锁定**（PRD 安全需求，必须实现），锁定态禁用提交并 Toast 提示。
- **鉴权流**：登录成功进入仪表盘；未登录访问受保护路由 → 跳登录页；接口越权返回 403 → 前端提示并停留在安全页。
- **退出**：清空会话回登录页。

### 4.3 导航与 RBAC 驱动 UI（对齐 PRD 2.3 / 5.8）

- **菜单按权限过滤**：`buildSider()` 依据 `can(role, perm)` 仅渲染有权菜单项；无子项的父级隐藏。
- **无权限占位**：进入受限页（如留言/用户/角色）显示「无访问权限」卡片，注明当前角色与缺失权限码，对应接口 403。
- **权限基线**：沿用 PRD 2.3 权限矩阵（15 项 `资源:操作`）；v1.2 起角色权限为**预设分配**，后台「角色与权限管理」界面**无逐权限勾选矩阵**（仅维护名称/描述）。
- **角色徽章**：Header 右侧显示当前角色（super_admin→蓝、content_editor/operator→默认），头像首字母。

## 5. 无障碍与合规专项

### 5.1 无障碍基线（WCAG 2.1 AA）

| 项 | 要求 | 实现要点 |
|---|---|---|
| 对比度 | 正文/背景 ≥ 4.5:1 | 前台 `--text-2:#5A524A`(7.17:1) / `--muted:#6E655B`(5.35:1) on `#FAF7F2`；后台 `--text-2:#595959`(7.0:1) / `--muted:#6B6B6B`(5.33:1) on `#fff`，均满足 AA |
| 键盘可达 | 全功能可键盘操作 | 导航、菜单、模态、表单、分页均可 Tab/Enter；`Esc` 关模态/抽屉 |
| Focus 环 | 可见聚焦态 | 前台 `outline:3px solid var(--gold)`；后台 `outline:2px solid var(--primary)` |
| 语义标签 | 结构正确 | `header/nav/main/footer/aside`；标题层级 `h1→h4` 不跳级 |
| 图标/控件 | 可访问名 | 功能性图标 `aria-label`；装饰图标 `aria-hidden` |
| 表单 | 关联 label | 每个输入有 `<label>` 或 `aria-label`；必填用 `required` + `*` |
| 下拉菜单 | 状态暴露 | `aria-haspopup` / `aria-expanded` 随开合切换 |
| 动画降级 | 尊重系统 | `@media (prefers-reduced-motion:reduce)` 全量关闭 |

### 5.2 个人信息合规（PIPL，对齐 PRD 8.1）

1. **告知同意**：留言表单明示收集目的与范围，勾选《隐私政策》为提交前置（必填）。
2. **最小必要**：仅收姓名、电话（必填），邮箱选填；不收无关字段。
3. **存储与保留**：手机号加密存储，建议保留 ≤ 24 个月到期清理/匿名化（运维侧）。
4. **访问控制**：仅客服/运营角色可见；列表/详情脱敏展示。
5. **不共享**：本期不向第三方共享/出售。
6. **前端义务**：表单 `pattern` 校验电话；提交即视为同意的提示文案不可省略。

### 5.3 内容与链接安全（对齐 PRD 8 安全）

- **富文本 Sanitize**：新闻正文、企业资料富文本在渲染前须经 XSS 过滤（白名单标签/属性，剥离 `script`、`on*` 事件与危险协议）；后台编辑器与前端展示共用同一清洗规则。
- **跳转链接白名单**：轮播图/Banner 的 `link_url` 仅允许 `http(s)://` 协议，禁止 `javascript:` / `data:` 等；站内链接走相对路径或路由。
- **输入校验**：所有表单/接口沿用 PRD 7.8 参数校验；URL、电话、邮箱等前端先行校验，后端二次校验，防注入。
